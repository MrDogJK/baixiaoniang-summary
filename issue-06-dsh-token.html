签到积分，
换成免费 token

不是破解，也不是白嫖：一个签到攒积分的控制台，在你手机上起一个本地网关， 把它接的模型（含 DeepSeek V4.1 Flash）转成标准 API，再填进 DSH Go 当自定义渠道。 两步就通，但有两个细节容易卡住。

13积分

UP 主实测：13 积分能跑约 300 万 token，速度是正常速度。 新用户送 2000 积分，每天签到再给 100。 — 折合下来几乎是白给，代价在别处

01

它到底是什么：一台跑在你手机上的中转A local gateway

整件事的结构很简单，看清结构就不会被步骤绕晕：

L1

控制台（WorkBuddy）

签到攒积分，用积分调用它接入的模型；它同时能在本机起一个网关服务

↓
L2

本地网关

把上游模型包装成标准 API：给一个地址 + 一个 API Key，走本机

↓
L3

你的客户端

DSH Go 等，把 L2 当成「自定义渠道」填进去，之后正常对话

本质：积分换了上游额度，本地网关换了协议——两边都不是你的

03

三步：起网关、拿钥匙、填进去Three moves

第一步 · 起网关

  • 打开控制台，点启动本地网关
  • 账号 → 添加账号（国内版、国际版都行），登录

第二步 · 拿两样东西

  • 地址：在网关日志/地址栏里长按复制最后一栏
  • API Key：控制台设置 → 滑到底 → 服务器配置 → 复制 api_key

第三步 · 填进客户端

  • DSH Go：菜单 → 设置 → 模型 → 添加自定义渠道 → 名称 + 地址 + Key → 拉取模型 → 勾选 → 保存

06

另一个客户端：同一套地址与 KeySame in the other app

流程几乎一样，差别在于入口：新增渠道时选 OpenAI 兼容那一项，地址和 Key 用刚才同一份。

填完 → 下滑 → 保存并获取模型 → 添加模型 → 回到菜单的「配置文件」，把对话模型切换成刚保存的那个。 最后这步很多人忘，结果还是用着默认模型。
07

一个必做的系统设置：别让后台被掐Keep it alive

因为网关跑在手机上，控制台被系统杀掉 = 整条链路断掉。所以视频里专门让你去改省电策略。

控制台 → 设置 → 滑到底附近找省电策略 → 改成无限制，才能让它在后台活着。
这一步的副作用要说清：它会常驻后台，更耗电、也可能占内存。这不是免费的。
08

画面里那条警告，比教程本身重要The warning

在「服务器配置」那一页，控制台自己写了一句话（画面里的原文意思）：

这份配置包含明文密钥。服务器的 api_key、各类 token 都以明文保存在配置里，本页会原样显示。 请勿截图外传；跨网络访问时务必使用 HTTPS 或内网环境。 — 控制台「服务器配置」页的提示

由此推出来的三条

  • 别把 Key 截图发出去——教程视频里演示时会打码，但很多人照做时忘了
  • 别让网关暴露到公网。默认走本机（127.0.0.1）最安全；一旦为了「别的设备也能用」把端口开放，等于把一个明文 Key 挂到网上
  • 积分和额度属于那个账号，不是你的。账号被封、活动结束、规则改了，链路当场断，写的东西还在，但工具没了
09

我的判断：能用，但别当基础设施What holds up

站得住

  • 技术路径是对的：本地网关 + OpenAI 兼容协议 + 自定义渠道，这套桥接方式在别处也通用，理解了以后换个上游同样能用
  • 「13 积分 ≈ 300 万 token」是他自己实测的，给了具体数字，不是空喊
  • 把「省电策略改无限制」这种细节讲出来，说明他真踩过

要打折

  • 这是拉新性质的教程：控制台需要新用户注册，视频本身就是入口；「大肥鱼」这类称呼带着明显的圈子推广味道
  • 「免费」的期限没交代：2000 积分和每日 100 是活动规则，随时可能变，视频里一个字没提有效期
  • 2 分半的视频塞了三个软件的设置路径，跳过和口误的地方不少（我自己转写时就有多处听不清）

一个反问（视频没回答）

  • 数据去哪了？请求从你手机 → 本地网关 → 上游服务商。中间那一跳看到了什么、存不存，教程不会说。用它跑私密内容要自己判断
  • 如果哪天要用它替代付费订阅，你其实把「可用性」押在了一个活动和一份明文配置上——省下的钱，是用稳定性换的
